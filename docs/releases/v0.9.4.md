# FuncGraph v0.9.4

## Highlights

- **Save and restore analysis views.** Timeline's **Tools → Saved views** keeps
  named positions, selections, applied filters, Find expressions, track state
  and Inline/Overhead basis. Optional notes and JSON import/export stay in the
  dialog rather than crowding the toolbar. Views are bound to the report's
  Timeline data; mismatched imports are rejected, not applied to another trace.
  Storage failures leave exportable tab-local views with an explicit warning.
- **Filter from the call you are inspecting.** Selected-call actions stage exact
  task and function filters for review before applying them. Drafts do not
  silently change the active filter or discard the current analysis context.
- **Quieter, clearer inline frames.** The Inline toggle sits beside **Fit trace**
  instead of inside Tools. Inline slices use complete dashed outlines and
  compact labels. Detail titles now simplify compiler-generated suffixes just
  like other display labels, while retaining original symbols in the model,
  source lookup and exports.
- **Safer BTF arguments for compiler clones.** Exact BTF prototypes for symbols
  such as `.isra` and `.constprop` take priority. If only the original function's
  prototype exists, the optional fast-source dependency (`pyelftools`) checks
  the matching ELF's DWARF parameter names, scalar types, widths and entry
  registers before reusing it. Changed, ambiguous or unprovable layouts remain
  raw; the original prototype does not establish a clone's return type.
  Supported verification targets are x86-64 and AArch64 with DWARF 4/5.
- **Reproducible samples and releases.** Kernel and mixed reports, version
  badges and screenshots are refreshed without replacing recordings or losing
  source evidence. The bilingual release checklist now requires exact-commit
  CI and seven-file Pages acceptance before tagging, followed by verification
  of the published packages and their bundled uftrace/source manifests.

BTF function names are indexed once when loading the database. Repeated exact
lookups use that index rather than scanning all BTF types; clone verification
is batched and cached within the report. No dependency, missing DWARF or failed
ABI verification is a reason to guess parameter names or trim raw values.

## 主要改进

- **保存分析现场：**通过 **Tools → Saved views** 保存视口、选中调用或范围、已应用过滤、
  Find、轨道状态及 Inline/Overhead 基准；备注和 JSON 导入导出收在对话框内。
  保存内容绑定当前报告数据，拒绝不匹配的导入；存储不可用时提示并保留可导出的临时视图。
- **从调用生成精确过滤：**调用动作可生成任务、函数过滤草稿，确认后再应用，
  不会悄悄覆盖当前筛选或把未应用草稿当成已生效条件。
- **内联展示与符号统一：**Inline 开关放在 Fit trace 右侧，内联帧恢复完整虚线边框；
  详情标题同样简化编译器后缀，仅改变展示，不修改原始符号、源码解析和导出数据。
- **编译器克隆函数参数：**优先使用完整符号的精确 BTF 原型；仅存在原函数原型时，
  借助匹配 ELF 的 DWARF 严格核对参数名、标量类型、位宽及入口寄存器布局。
  参数被删除、重排、标量化或证据不全时保留 raw；不据此推断返回类型相同。
  支持 x86-64、AArch64 与 DWARF 4/5，缺少可选依赖时安全回退。
- **样例和发布流程：**更新内核、混合 HTML、版本标识和截图，保留真实记录与固定源码版本；
  发布前先验收同一提交的完整 CI 和 Pages，再推版本标签，并验证实际发布附件及隔离安装。

## Compatibility and validation

Python 3.8+ and existing text, raw and uftrace inputs remain supported. The
default output remains one offline HTML file. Existing recordings can be
replayed; previously generated HTML needs regeneration to obtain the new UI
and BTF interpretation. Saved views do not rewrite trace records or represent
a recording of every display preference.

Regression coverage includes generated ABI-changing GCC clones, x86-64 and
AArch64 DWARF 4/5 fixtures, missing/conflicting metadata, real-kernel sample
interpretation, browser interactions, raw decoding and installed distributions.
The shared release workflow separately tests Python 3.8/3.12 and builds native
x86_64/ARM64 wheels. Runtime system libraries and optional raw decoder libraries
remain host requirements; bundled uftrace is not bundled into the universal
wheel or sdist.

does not upload to PyPI or move an existing tag.
