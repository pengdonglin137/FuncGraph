# FuncGraph v0.9.5

## Highlights

- **Capture events alongside complete function graphs.** `fgcapture` and its
  shell compatibility entry point accept repeatable `-e` / `--event` selectors
  for scheduler, wakeup and other available kernel events. Text can hide event
  rows without deleting them. Host QEMU/KVM events use the existing Timeline;
  event-only recordings do not acquire invented function stacks.
- **More responsive large-report navigation.** Text stages large inline
  reports, reuses validated filter positions and duration order, and preserves
  pending filters across event-visibility changes. Timeline bounds hover
  previews, reuses overview and interrupt summaries, indexes interrupt queries
  and prepares CPU tracks in cancellable batches. These changes retain recorded
  identities and complete trace data rather than sampling away calls.
- **Filters that remain precise and usable.** Field selections match exact
  recorded values, preserve task names and support keyboard and touch input.
  Mixed boolean conditions retain all groups. Timeline and Compare move complex
  regex scans off the UI thread, preserve IME/native keyboard behavior and keep
  cancellation distinct from successfully applying a new result.
- **Bounded Compare browsing, complete exports.** Native Previous/Next controls
  browse 400 rows at a time while reusing the full filter/sort result. CSV still
  exports every matching row. On narrow or coarse-pointer layouts, a Filters
  menu groups settings without hiding summary metrics, paging or export.
- **Clearer details without overstating evidence.** User API failure hints are
  distinguished from kernel errno propagation; redundant raw returns move into
  disclosures. Inline labels require explicit evidence, tail-call chains can
  share proven return-site source context, and native entry excerpts are
  available without inventing caller positions. Display labels consistently
  simplify compiler suffixes while preserving original symbols for resolution
  and export.
- **Accurate flags and quieter controls.** Text and raw inputs preserve Linux
  latency states, including lazy rescheduling, and the pinned uftrace patch
  matches kernel depth formatting. Graph entry/return preempt calibration stays
  out of the normal UI. Fullscreen details, compact menus, help scrolling and
  keyboard panel resizing remain reachable in short viewports. Native Text
  links and copy feedback preserve the reading position.

Kernel-only `fgcapture.sh` uses automatic argument probing by default: it enables
`funcgraph-args` when a small probe is fast and compatible with return-address
output. An unavailable, slow, inconclusive or incompatible probe reports a
fallback that preserves caller sites. Use scoped `--args` to require arguments;
`--no-args` skips probing. Capture restores the previous tracefs state on exit,
so the option's value after capture is not proof of its value during capture.

## 主要改进

- **函数图与事件一起采集：**支持重复指定 `-e` / `--event`，选择调度、唤醒等现有内核事件；
  Text 可隐藏事件行但不丢弃记录。Host QEMU/KVM 事件沿用 Timeline，纯事件记录不伪造调用栈。
- **大报告交互优化：**分阶段准备 Text，复用完整过滤结果和耗时排序，保留事件显隐切换期间的
  待应用条件；Timeline 复用概览、悬浮与中断查询结果，分批准备 CPU 轨道且允许取消。
  优化不通过丢弃调用或改写原始标识实现。
- **过滤更准确易用：**字段选项精确匹配，保留任务名，兼容键盘、触屏和输入法；
  修复混合布尔条件的分组。复杂正则在后台扫描，取消不会冒充新结果已成功应用。
- **Compare 分页：**每页最多挂载 400 行，切页复用完整筛选和排序；CSV 始终导出全部匹配行。
  窄屏及粗指针布局将条件收进 Filters，保留汇总、分页与导出入口。
- **详情与源码证据：**区分用户 API 失败提示和内核 errno 链，折叠冗余 raw 返回值；
  内联标记要求明确证据，尾调用链共享有依据的返回点源码，函数入口片段不冒充调用位置。
  符号展示统一简化编译器后缀，后台解析和导出保留原始名称。
- **flags 与界面一致性：**保留包括 lazy resched 在内的 Linux 延迟标志，修正 uftrace
  深度格式；正常界面不暴露 preempt 校准细节。完善全屏详情、紧凑菜单、帮助滚动、
  键盘调整面板大小，以及 Text 原生链接、复制反馈和阅读位置保持。

`fgcapture.sh` 的纯内核采集默认自动探测参数能力：仅在探测快速且参数与返回地址能同时输出时
开启 `funcgraph-args`，否则说明降级原因并优先保留调用点。显式使用 `--args` 要求参数，
慢内核需通过命令或 `-g` / `-p` 限定范围；`--no-args` 跳过探测。采集结束恢复原 tracefs
设置，不能仅凭结束后的选项值判断采集期间是否开启。

## Compatibility and validation

Python 3.8+ and existing text, raw and uftrace inputs remain supported. The
default report is still one offline HTML file; existing HTML must be
regenerated to receive viewer changes. Kernel and mixed public samples retain
their recordings, source revision, arguments, call sites and complete models.

Focused regression coverage includes capture defaults and restoration, event
selection, mixed Text filters, browser navigation and input handling, complete
Compare exports, source provenance, latency flags and raw decoding. A paired
10,000-row Compare check verifies unchanged complete model and CSV hashes while
bounding attached rows at 400. This is not a universal startup, heap-use or
per-action speed guarantee, nor a claim that every possible trace was tested.

The release workflow separately checks Python 3.8/3.12 and builds native x86_64
and ARM64 wheels. Bundled uftrace is included in native release wheels, not the
universal wheel or sdist; runtime system libraries and optional raw decoder
libraries remain host requirements. A local tag does not itself publish those
artifacts or deploy Pages. Follow the release checklist before pushing it.
