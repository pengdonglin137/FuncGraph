# FuncGraph v0.9.3

## Highlights

- **One capture entry point.** `fgcapture --kernel`, `--user` and `--mixed`
  select kernel-only, instrumented user-only or same-run user/kernel recording.
  User/mixed capture requests arguments, returns and caller sites by default;
  mixed capture includes available scheduling and exec/exit events and checks
  and restores idle tracefs settings. Native Linux x86_64/ARM64 wheels continue
  to include the pinned, patched uftrace and matching recording libraries.
- **Faster large Text reports.** Complete inline Text at 4,096 rows or more
  now skips offscreen rendering in supported browsers. Repeated Timeline → Text
  entry avoids repainting the full tree while retaining native selection,
  source panels, complete long lines and their horizontal extent. Initial
  preparation and full-model operations can still be expensive.
- **Opt-in windowed sidecar Text.** Newly generated chunked sidecars can mount
  a bounded row window, with complete-record filtering, folding, task/duration
  ordering, source expansion and navigation. Task captions remain visible after
  their original heading leaves the window. Cooperative sorting, batched
  visibility updates, resource-local reads and bounded checksum workers reduce
  repeated work. This is not a bound on total model/Timeline memory; full Text
  remains the default and whole-document operations retain an explicit full mode.
- **Responsive view switching and hover.** View tabs stay reachable while
  reading deep Text. Native Text selections are suspended before hiding the
  view and restored on return, avoiding hidden-source hit-testing costs.
  Timeline coalesces pointer updates with canvas frames, keeps details/source
  evidence intact and retains painted slices during detail-panel resizing.
- **Clearer Timeline details.** Total-time and self-time color modes sit beside
  context coloring. Ordered call facts and recorded flags are visible without
  a separate metadata disclosure; selected-call actions use a compact menu.
  Compiler-generated suffixes are simplified for display only—original symbols
  and recorded relationships are not rewritten. Mixed context and task/CPU
  coverage remain distinct from assumptions about a process's lifetime.
- **A usable project entry point.** Redesigned English/Chinese READMEs lead with
  the mixed demo, then installation, offline replay, all three capture modes,
  separate source/type configuration and large-report choices. Scenario guides
  and the pigz + zlib case cover reproducible workloads and saved artifacts.

The default remains one offline HTML file. Sidecar delivery is explicit, or
selected only above a user-supplied complete-HTML byte threshold in `auto` mode.
The 4,096-row rendering threshold does not change that output-selection rule.
Recorded data, raw arguments, kernel BTF interpretation, user DWARF names,
caller-site evidence and separate user/kernel source handling remain available.

## 主要改进

- **统一采集：**`fgcapture` 覆盖纯内核、纯用户和混合模式；用户／混合模式默认请求参数、
  返回值和调用点，混合模式包含可用的调度与 exec/exit 事件，并保护、恢复 tracefs 设置。
  Linux x86_64／ARM64 wheel 继续内置固定版本、已打补丁的 uftrace 与采集库。
- **大型 Text 优化：**4,096 行起的内嵌 Text 自动跳过屏外渲染，减少反复切换视图的重绘；
  保留完整行、长参数横向宽度、源码和原生选区。首次准备仍有开销。
- **可选窗口化：**新分块 sidecar 可手动启用 Windowed Text，配合完整记录模型进行过滤、
  折叠、排序、导航和源码展开；改进任务标题、协作式排序、可见性更新和资源读取。
  它只限制挂载行数，不代表限制整个报告内存，默认仍使用完整 Text。
- **交互与可读性：**滚动后仍可切换标签；修复隐藏 Text 选区引起的 hover 延迟，合并鼠标更新，
  保持详情拖动时 slice 可见。增加耗时配色、直接展示有序调用指标与 flags，使用紧凑动作菜单。
  编译器后缀仅在展示时简化，不改写真实符号或调用数据。
- **文档与样例：**重设计中英文 README，补充场景用例、统一采集和 pigz + zlib 案例入口，
  发布样例使用最新界面。单文件、sidecar、自动大小阈值和实验性窗口化的边界分别说明。

## Validation and compatibility

The shared CI/release workflow validates Python 3.8 and 3.12, browser behavior,
raw decoder builds, native x86_64/ARM64 uftrace exports, and installed wheel/sdist
commands. The guides' offline recipes, parser options, local links and bilingual
shell blocks have executable regression coverage. Optional real-kernel cases
require their documented images and source trees.

See [view-switch measurements](https://github.com/pengdonglin137/FuncGraph/blob/v0.9.3/docs/performance-view-roundtrip.md),
[windowed Text limits](https://github.com/pengdonglin137/FuncGraph/blob/v0.9.3/docs/performance-text-window.md) and the
[viewer guide](https://github.com/pengdonglin137/FuncGraph/blob/v0.9.3/docs/viewer.md) for reproducible performance checks rather than
universal speed or memory claims. Kernel-only text and saved FuncGraph JSONL
remain usable without a local uftrace executable. Raw trace-cmd input still
needs its separate optional native decoder libraries.

## Install and view the updated samples

Download the wheel matching `uname -m` and verify `SHA256SUMS` before installing:

```bash
sha256sum --check SHA256SUMS
python3 -m pip install './funcgraph-0.9.3-py3-none-linux_x86_64.whl[all]'
fguftrace --version
funcgraph --help
fgcapture --help
fgreport --help
```

Replace `linux_x86_64` with `linux_aarch64` on ARM64. Platform wheels need
compatible glibc and system shared libraries; the Python-only wheel/sdist does
not include a compiled recorder. This workflow publishes GitHub Releases, not
PyPI. Published tags are not moved.

The successful `master` CI deploys the homepage, kernel/mixed HTML and screenshots
to GitHub Pages; the tag workflow separately publishes Release attachments.
Existing generated reports need regeneration to obtain the new viewer, without
changing the original recordings.
