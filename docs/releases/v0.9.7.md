# FuncGraph v0.9.7

## Highlights

- **Filter Text by event type without typing.** Pick a recorded event from the
  Text toolbar and combine it with CPU, task and search filters. Event choices
  come from the recording, including event names without a known subsystem.
- **Browse large reports and call details more easily.** This release includes
  post-v0.9.6 improvements to report preparation, filtering and navigation.
  Open an available BTF prototype from the call header in Timeline.
- **Start with capture, then generate a report.** The bilingual quick start
  explains `fgcapture`, `fgreport`, optional presets and manual overrides.
  The CLI reference lists each flag and where to pass it.
- **Use an installed `fgcapture` with `sudo`.** The launcher checks for its
  bundled shell helper beside the installed executable before falling back to
  `PATH`. The capture completion message shows how to run `fgreport`.
- **See why a thread blocked on supported Android kernels.** `fgcapture --sched`
  and default mixed capture include `sched:sched_blocked_reason` when available.
  Timeline and Wait chain show the recorded blocking site and I/O-wait flag
  when the event matches a wait; missing evidence is not treated as `No`.
- **Try the updated online examples.** The kernel and mixed reports use the
  new viewer and retain the original recorded calls and source context.

## 主要改进

- **Text 事件下拉筛选：**直接选择记录中的事件类型，可与 CPU、任务和文本搜索叠加。
- **浏览大报告和调用详情：**改进报告准备、筛选和导航；Timeline 支持从调用标题查看已有的 BTF 原型。
- **按实际流程入门：**双语 README 先讲采集和生成报告，再讲可选的 preset 和手动参数；完整参数集中查阅。
- **修复 `sudo` 下的采集启动：**已安装的 `fgcapture` 优先从同目录找配套脚本，再查 `PATH`；采集完成后提示用 `fgreport` 生成报告。
- **查看 Android 线程阻塞原因：**内核支持时，`fgcapture --sched` 和默认混合采集会记录 `sched:sched_blocked_reason`。成功关联到等待区间后，Timeline 和 Wait chain 显示阻塞位置及 I/O wait 标记；缺失不等于 `No`。
- **刷新在线示例：**纯内核与混合报告更新到新版界面，保留原始调用与源码信息。

## Compatibility / 兼容性

Python 3.8+ and existing input formats remain supported. Regenerate an existing
offline report to use the updated viewer. Linux x86_64 and aarch64 native wheels
bundle patched uftrace; the portable wheel and sdist do not. Recording still
depends on the host kernel, permissions and installed runtime libraries.

已生成的离线报告需要重新生成才能使用新版界面。原生 wheel 自带 uftrace，通用 wheel 和
源码包不带；实际采集能力仍取决于内核、权限和系统库。
