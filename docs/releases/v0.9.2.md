# FuncGraph v0.9.2

## Highlights / 主要改进

- Trace user and kernel calls together with uftrace, or open either address
  space on its own. Mixed views retain user/kernel boundaries, recorded context
  flags, parameters, returns and separate source-resolution options.
- Linux x86_64 and ARM64 wheels include the pinned, patched uftrace executable,
  its recorder libraries, required runtime files, license and corresponding
  source. Explicit executable overrides remain available; ordinary installed
  commands prefer the bundled recorder.
- User arguments retain DWARF names, decode recorded strings and enums, and
  identify saved prototype names separately from DWARF. Unknown names remain
  explicit captured slots. Call sites use saved caller symbols and offsets,
  based on the caller return PC minus one, without confusing the callee entry
  with its calling instruction.
- Kernel BTF trims captured argument counts and scalar widths and normalizes
  signed returns, pointer values and void returns without discarding raw bits.
- Timeline adds grouped Tools, full-screen viewing, compact touch controls,
  pinch/pan gestures, precise viewport positioning and expandable details.
  Full screen hides the address-space legend while preserving call boundaries.
- Large-report improvements include record-aligned sidecar Text chunks,
  bounded source caching, shared filter records, paged analysis panels,
  viewport-aware drawing and cooperatively prepared function-search indexes.
- Details prioritize call facts, wrap complete argument items, use consistent
  semantic colors and keep raw evidence available in disclosures. Filtering
  distinguishes draft queries from the active shared filter.
- Kernel links can target GitHub or Elixir at an explicit revision. Refreshed
  kernel and mixed samples use the matching Linux `v7.4-rc2` sources; user
  sources do not use the kernel source browser.

支持用户态、内核态及混合调用全流程，Linux x86_64 / ARM64 安装包自带固定版本、已打补丁
的 uftrace。参数保留名字和原始证据，用户调用点使用真实保存的调用方符号和偏移；内核
BTF 修正参数数量、位宽及返回值。Timeline 增加分组工具、全屏、触屏操作和详情扩展，
大报告使用按需加载、分页与视口裁剪；样例和源码链接同步更新。

## Correctness and CI / 准确性与构建

- Fix private native-library installation metadata so libtracefs links against
  libtraceevent in the selected prefix instead of a missing/default lib64 path.
  Pin all four native dependency repositories to exact commits.
- Native-wheel CI checks export fields, parameter names, strings/enums, caller
  sites and raw detail delivery on both supported architectures, then installs
  each wheel outside the original source/build prefix.
- CPU rows distinguish **observed call coverage** from recorded scheduling.
  Without actual `sched_switch` records, dashed segments and their tooltip
  identify observation spans rather than continuous CPU runtime or task start.
  In the mixed sample, `main` starts at 0 while the first CPU4 kernel observation
  is at 5.775459 ms; earlier user CPU placement is unknown, not shifted to CPU4.
  See [CPU coverage](../cpu-coverage.md) for the exact recorded timestamps.

修复 raw 库在私有安装目录中的链接路径，避免 `cannot find -ltraceevent` 阻断打包和 Pages。
第三方源码全部固定 commit。混合样例中 CPU4 的首条内核观测不等于 `main` 入口；缺少实际
调度记录的 CPU 区间明确标记为观测跨度，不补造运行区间、不改写原始时间。

## Assets and installation / 附件与安装

The Release supplies two Linux platform wheels, the Python-only wheel, the
Python source distribution, the patched uftrace corresponding-source archive
and `SHA256SUMS`. GitHub's automatically generated repository archives are
additional source snapshots, not substitutes for the native corresponding
source attachment.

Download the Linux wheel matching `uname -m` (`x86_64` or `aarch64`) and install:

```bash
python3 -m pip install './funcgraph-0.9.2-py3-none-linux_x86_64.whl[all]'
fguftrace --version
funcgraph --help
fgcapture.sh --help
fgreport --help
```

Replace `linux_x86_64` with `linux_aarch64` on ARM64. Raw trace-cmd decoding
still requires its native decoder libraries; the uftrace wheel does not remove
that separate prerequisite. The Python-only wheel has no bundled native
recorder and can use an explicitly installed uftrace.

用 `uname -m` 选择对应平台 wheel；ARM64 替换文件名中的架构。raw trace-cmd 解码仍需对应
native 库，不因安装 uftrace wheel 而自动满足。校验附件前先执行
`sha256sum --check SHA256SUMS`。本流程发布到 GitHub Releases，不是 PyPI。

Published examples are deployed by the successful `master` CI's Pages job,
not by the tag's release job. Old generated HTML needs regeneration to obtain
the updated viewer; saved trace records are unchanged.

公开样例由 `master` CI 全部通过后的 Pages job 更新，标签发布不会代替 Pages 部署。
已有 HTML 需重新生成以使用新界面；原始 trace 记录保持不变。
