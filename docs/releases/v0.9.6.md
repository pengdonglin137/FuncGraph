# FuncGraph v0.9.6

## Highlights

This release includes the improvements prepared locally for v0.9.5 and the
subsequent capture-default correction. The existing local v0.9.5 tag is not moved.

- **Consistent kernel capture defaults.** `fgcapture.sh` enables available
  `funcgraph-args`, retval, retaddr and latency options independently. It no
  longer probes argument-formatting speed, disables other fields automatically
  or requires a function/PID/command scope. `--args` explicitly enables arguments;
  `--no-args` disables only arguments. Unsupported options are reported and
  skipped. Actual output still depends on the kernel, and prior tracefs settings
  are restored by default.
- **Function graphs and events together.** Repeatable `-e` / `--event` selectors
  add scheduler, wakeup, KVM and other available events without requiring a
  function filter. Text can hide event rows without discarding them. Event-only
  input does not acquire invented function stacks.
- **More responsive large reports.** Text stages large reports and reuses
  validated filter positions and duration order. Timeline bounds hover previews,
  reuses overview and interrupt summaries, and prepares CPU tracks in
  cancellable batches. Optimizations preserve complete recorded calls and
  original identities rather than sampling away data.
- **Precise filters and bounded Compare browsing.** Exact field selections,
  mixed boolean groups, keyboard/touch/IME handling and cancellable regex scans
  remain consistent. Compare mounts at most 400 rows per page while CSV exports
  all matching rows; narrow layouts keep summary, paging and export reachable.
- **Clearer details and source evidence.** User API failure hints remain
  distinct from kernel errno propagation. Raw returns are available on demand.
  Inline labels require evidence, proven tail-call chains can share return-site
  source context, and function-entry excerpts do not masquerade as caller sites.
  Display names simplify compiler suffixes while resolution and export retain
  original symbols.
- **Accurate flags and compact controls.** Text and raw inputs preserve Linux
  latency states including lazy rescheduling; patched uftrace matches kernel
  depth formatting. Preempt calibration stays out of the normal UI. Fullscreen
  details, menus, help, keyboard resizing and Text links retain usable navigation.

Complementary call trees, aggregated flame graphs and scoped interaction diagrams
are recorded in TODO only. This release does not implement these proposed views.

## 主要改进

- **内核参数默认开启：**内核提供 `funcgraph-args` 就启用，与 retval、retaddr 等选项独立
  配置；移除速度探测、自动关闭其他字段和强制范围限制。`--no-args` 仅关闭参数，不支持的
  选项提示并跳过。实际字段仍由内核决定，采集结束默认恢复原 tracefs 设置。
- **完整函数图与事件一起采集：**重复指定 `-e` / `--event` 选择调度、唤醒、KVM 等事件；
  Text 可隐藏事件行但不删除数据。纯事件记录不伪造函数调用栈。
- **大型报告交互优化：**分阶段准备 Text，复用过滤和耗时排序；Timeline 复用悬浮、概览与
  中断查询结果，分批准备 CPU 轨道并支持取消，不通过丢弃调用提升速度。
- **过滤与 Compare：**精确字段、混合布尔条件及键盘、触屏、输入法行为保持一致；复杂正则
  可取消。Compare 每页最多挂载 400 行，CSV 仍导出全部匹配结果，窄屏保留关键入口。
- **详情与证据：**区分用户 API 失败提示和内核 errno 链，按需展示 raw 返回值；内联、
  尾调用和函数入口源码遵守证据边界。展示名称简化编译器后缀，后台保留原始符号。
- **flags 与界面：**保留 lazy resched 等延迟标志并修正 uftrace 深度格式；正常界面隐藏
  preempt 校准细节，完善全屏、菜单、帮助、面板调整和 Text 阅读位置保持。

调用树、聚合火焰图和局部交互时序图仅列入 TODO，本次没有新增这些视图。

## Compatibility and validation

Python 3.8+ and existing text, raw and uftrace inputs remain supported. The
default report remains a single offline HTML file. Regenerate existing HTML to
receive viewer changes. Public kernel and mixed samples retain the matching
Linux v7.4-rc2 source revision, original records, arguments, caller sites and
source information.

Real QEMU Linux 7.4.0-rc2 checks cover default, explicit `--args` and `--no-args`
capture. Arguments appear in the first two modes; retval, retaddr and latency
remain enabled in all three. All 73 snapshotted tracefs settings restore after
each capture. Missing-option behavior is covered by fake tracefs, not claimed
as a real old-kernel test or a universal formatting/performance guarantee.

Release acceptance includes the full local test suite and browser checks,
dependency pins and patches, raw decoding, distributions and isolated installs.
The workflows independently gate Python 3.8/3.12 and native Linux x86_64/aarch64
wheels. A passing local check does not substitute for remote matrix acceptance.
Native wheels include patched uftrace, recording libraries, license and complete
corresponding source; the universal wheel and sdist do not bundle the executable.
System runtime libraries and optional raw decoder libraries remain host requirements.
